## Measurement fix delivered in this review

The previous worker called `buildDocumentScene` in Node in image rendering, direct PDF rendering and export orchestration. It therefore used estimated text metrics. PPTX reported the estimates; PDF had a separate reporting defect: its adapter did not inspect scene text metrics at all, so its false flag did not prove browser measurement.

The worker now records complete `MeasureRequest` values in an estimator-backed first pass, sends one batch to Chromium, and rebuilds from a synchronous cache. The browser runs the existing renderer `createDomMeasurer`, including paragraphs and shrink-to-fit searches. Requests include content, typography, width, height, fit mode and font-size bounds. This avoids duplicating the measuring algorithm or assuming that the browser's shrink search probes the estimator's intermediate sizes.

Browser font availability accompanies the results. Caches belong to one page/document, and a genuine second-pass miss falls back with `estimated: true`. The final scene is shared by the export adapter and PDF renderer. Image reports and PDF/PPTX reports inspect actual text metrics, including nested text. Browser availability is now required for PPTX as well as PDF; the worker has a direct `esbuild` dependency to bundle the shared measurement code in memory. Host font differences can still change output; browser measurement is not a cross-machine font guarantee.

Changed implementation: [text-measurement.ts](../apps/worker/src/text-measurement.ts), [measurement-browser.ts](../apps/worker/src/measurement-browser.ts), [worker orchestration](../apps/worker/src/index.ts), [render.ts](../apps/worker/src/render.ts), [export metric helper](../packages/export-core/src/index.ts), [PDF reporting](../packages/export-pdf/src/index.ts). [CLAUDE.md](../CLAUDE.md) explains the contract and runtime prerequisite. The worker browser tests run in the existing CI export job after Chromium installation.

The earlier malformed-known-element defect also remains fixed: runtime and emitted schema exclude registry-known types from the loose unknown fallback, recursive errors name missing fields, and true unknown types/enum values survive. Its regression checks were rerun; see the [earlier audit's fix record](PHASE_0_TO_7_IMPLEMENTATION_AUDIT.md). The renderer's defensive line placeholder remains intact. No schema-version bump or new document API shape was introduced.
