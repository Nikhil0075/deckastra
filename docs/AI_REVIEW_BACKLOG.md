## Research and proposed fixes for a later phase

1. **Compare rendered pixels with source geometry.** The current critic sees
   source data and deterministic findings, not the reviewer's slide images.
   Google's [image-input documentation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/image-understanding)
   supports sending image bytes together with text. Proposed application:
   supply a bounded render of the selected scope, bind it to deck/version,
   font/asset checksums and animation state, and require visual issue locations.
   First reproduce slide 1's title collision and slide 15's missing final
   counter in the actual app, worker and exported PDF. Fix parity before using
   a mismatched screenshot as evidence. Missing fixture assets stay disclosed.
   Visual inspection does not establish factual truth.
2. **Distinguish internal consistency from independent verification.** Build
   an evidence graph from selected text, chart/table data and expressly supplied
   supporting material. For example, 420→260 ms implies about 38% reduction;
   that checks the arithmetic, not the provenance of the measurements. A missing
   external citation warrants a proportionate disclosure; a causal explanation
   such as monsoon outages needs actual causal evidence. Element scope may
   receive narrowly linked, read-only context only with an explicit contract;
   it must never acquire write authority over adjacent elements.
3. **Derive verdicts from classified issues.** Route reading-order/overlap
   findings to layout/accessibility; story defects to story; missing assets or
   descriptions to creative. A pass must be rejected when a required disclosure
   remains unmet. Reserve blocker severity for a concrete blocking defect.
   Treat planted instructions as untrusted content without treating ordinary
   uncited deck statements as security incidents.
4. **Add meaningful deterministic visual checks.** Measure real glyph bounds,
   overlaps, diagram-label collisions and effective font sizes at presentation
   scale. Evaluate sparse composition separately from factual correctness.
   Summaries must identify what was inspected; no narration-check claim without
   cue evidence.
